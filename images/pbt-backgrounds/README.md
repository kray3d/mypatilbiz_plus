# PBT background images

Place one background image for each PBT card in this folder.

Use the same base filename as the PBT logo, with a `.jpg` extension:

- `mbip.jpg` for the MBIP announcement panel
- `mdsb.jpg` for MD Sabak Bernam
- `mpaj.jpg` for MP Ampang Jaya
- `mdkampar.jpg` for MD Kampar

The remaining PBT backgrounds follow the logo filenames in `public/logos/pbt/`.
If a background is missing, the existing gradient and skyline placeholder remain visible.
